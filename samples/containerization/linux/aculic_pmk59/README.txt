aculic_pmk59

A directory to hold your extend license files for the products to be run in
the container. pmk59 indicates the licenses are for Linux 64-bit shared
products. For this sample you will need to copy the following license files
to this directory:
    Filename           Product
    ------------------ -------
    acurcl.alc         AcuRCL
    acurcl.wlc         AcuToWeb
    runcbl.alc or .3lc Runtime
