aculic_win_x64

A directory to hold your extend license files for the products to be run in
the container. win_x64 indicates the licenses are for Windows 64-bit products.
For this sample you will need to copy the following license files to this
directory:
    Filename           Product
    ------------------ -------
    acurcl.alc         AcuRCL
    acurcl.wlc         AcuToWeb
    wrun32.alc or .3lc Runtime
