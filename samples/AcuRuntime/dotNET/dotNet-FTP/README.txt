This program uses the .NET DLL from FluentFTP - https://github.com/robinrodricks/FluentFTP

Place the FluentFTP.dll in the bin directory of your Acu installation.

You will need to edit the FTP details in the source before you compile it.

Compile - ccbl32 -ga -sp . FluentFTP.cbl

Run - wrun32 -d FluentFTP.cbl
