In the extend C:\Users\Public\Documents\Micro Focus\extend 10.2.0\sample\AcuToWeb directory 
you will find the css-example.cbl program. 
There is a 10-2-example.css file, as well as a harvest.css file. Finally there is a gateway-10-2.conf
AcuToWeb Gateway configuration file.

Create an AcuConnect alias for the css-example program
Start AcuToWeb using the gateway-10-2.conf configuration file
Use a browser and navigate to http:\\127.0.0.1:3000
In the Gateway Connection setup, enter the alias name you created. You should also see a Theme drop down box.
Select the Harvest theme and use the Connect button to see the program.

To see the 10.2 ATW-CSS-CLASS and ATW-CSS-ID properties
In the Gateway Connection setup, enter the alias name you created. You should also see a Theme drop down box.
Select the 10-2 theme and use the Connect button to see the program.
